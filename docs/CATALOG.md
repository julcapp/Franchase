# Товары и комплектующие

## Категории
1. Смеси: сухие/жидкие, ваниль/шоколад и другие, фасовка, состав, условия хранения.
2. Сиропы/топпинги/джемы/посыпки: вкусы, объём, совместимость и аллергенность.
3. Вафельные стаканчики и рожки: размер, форма, упаковка, количество.
4. Бумажные стаканчики: объём, материал, дизайн, крышки, брендирование.
5. Запчасти: модель аппарата, артикул, совместимость, наличие.
6. Обслуживание: щётки, расходники, разрешённые чистящие средства.

## Данные товарной карточки
`sku, slug, title, category, description, images, unit, packSize, priceRetail, pricePartner, availability, compatibility, manufacturer, documents, isActive`.

В MVP не показывать фиктивные цены и «в наличии» без источника. Кнопки «Уточнить ассортимент» могут готовить черновик сообщения, но нельзя изображать успешную отправку.

## Этапы
Категории → карточки → запрос ассортимента → backend заявок → корзина → онлайн-оплата → склад → кабинет партнёра.
