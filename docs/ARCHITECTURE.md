# Архитектура

## Этап 0: статический прототип
`index.html`, CSS и JS без сборщика. GitHub — источник версий. GitHub Desktop — локальная работа на Home-Boss.

## Целевая архитектура (требует решения)
- Frontend: адаптивные страницы каталога, продукта, оборудования, партнёров и личного кабинета.
- API: заявки, товары, цены, доступность, заказы, платежи, согласия.
- PostgreSQL: каталог/остатки/заявки/согласия/журнал изменений.
- CMS/админка: фото, карточки оборудования, товарный каталог, акции.
- Интеграция: существующий контур платформы «У Тимоши», ЮKassa, MAX/Telegram, по отдельному решению — CRM.
- Не переносить токены и пароли в Git. Production не менять без проверки и согласования.
- Деплой: staging → проверка → production. Доменные имена и сервер публикации ещё не утверждены.

## Правило для изображений
Оригинальные утверждённые фото хранить в `assets/images/` в оптимизированных форматах, с понятными именами и alt-текстами; при необходимости сохранять оригиналы отдельно. Не использовать изображения с текстом «Счастье в каждом стаканчике».
