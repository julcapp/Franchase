# Журнал решений

1. Внутреннее имя проекта: **Franchase**; его не показывать посетителям.
2. Публичный бренд-платформа: **«У Тимоши»** (не сводить к одной «франшизе мягкого мороженого»).
3. Неизменяемый текст на фирменном стаканчике и основной слоган: **«Счастье в одном стаканчике»**.
4. «Собери свой вкус» — CTA для покупателей; «Открой вкусный бизнес» — для партнёров.
5. Сайт объединяет B2C (десерт), B2B (оборудование/готовый бизнес) и B2B-магазин ингредиентов/упаковки/запчастей.
6. Фотографии десертов предоставлены заказчиком в беседе 2026-11-21; фотографии реальных аппаратов должны быть добавлены позже.
7. Не публиковать вымышленные показатели продаж, прибыль, окупаемость или число точек.
8. Технический каталог, калькулятор и форма могут начинаться как демонстрационные, но должны быть промаркированы.
9. Рабочая станция для локального клона: **Home-Boss**, GitHub Desktop; удалённый репозиторий `julcapp/Franchase`.
