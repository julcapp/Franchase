# Карта страниц и индексов

| URL / якорь | Блок | Статус |
| --- | --- | --- |
| `/`, `index.html` | Главная / hero | MVP |
| `/#platform` | Платформа «У Тимоши» | MVP |
| `/#machines` | Аппараты / оборудование | карточки-заготовки, фото ожидаются |
| `/#flavors` | Собери свой вкус | интерактивный прототип |
| `/#catalog` | Сопутствующие товары | категории-заготовки |
| `/#partners` | Партнёрам / открытие бизнеса | MVP |
| `/#project` | Наш проект «У Тимоши» | MVP, без вымышленных метрик |
| `/#contact` | Обратная связь | демо, без отправки |

Будущие маршруты: `/catalog/`, `/catalog/product/:slug`, `/machines/:slug`, `/partners/`, `/privacy/`, `/offer/`, `/admin/`. Не создавать пустые index-страницы лишь для имитации готовности.
