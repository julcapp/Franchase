# У Тимоши — платформа (Franchase)

**Franchase** — внутреннее имя проекта и репозитория, не публичное название сайта.

Публичная платформа: **«У Тимоши»**. Фирменный слоган: **«Счастье в одном стаканчике»** (не «в каждом»).

## Текущая структура

- `index.html` — главная страница и интерактивный прототип
- `assets/` — ресурсы оформления (планируются фото аппаратов и утверждённые изображения десертов)
- `docs/PAGES.md` — карта страниц, секций, якорей
- `docs/FUNCTIONS.md` — функциональный реестр, статусы реализации
- `docs/ARCHITECTURE.md` — архитектура и интеграции
- `docs/CATALOG.md` — товарные категории и будущий магазин
- `docs/ROADMAP.md` — этапы разработки и приоритеты
- `docs/DECISIONS.md` — зафиксированные решения и ограничения
- `CHANGELOG.md` — история изменений

## Запуск

Откройте `index.html` в браузере; для локальной разработки: `python -m http.server 8080`, затем http://localhost:8080/.

## Важно

Репозиторий пока содержит **новый компактный Git-совместимый прототип**. Предыдущая автономная версия `utimoshi_platform_catalog.html` со встроенными изображениями хранится как файл в рабочей беседе и должна быть отдельно импортирована в репозиторий вместе с оригиналами изображений: не заявляем, что она уже опубликована здесь.

Формы не отправляют персональные данные без backend. Расчёт доходности — только иллюстрация, не гарантия. Перед запуском требуются юридические тексты и проверка товара/цен.
